# Precious Nkomose Restaurant Reservation and Menu Management System

## Project Overview

The Precious Nkomose Restaurant Reservation and Menu Management System is a web-based system developed for Precious Nkomose (Pty) Ltd. The system is designed to improve the way restaurant reservations, menu information and customer-related activities are managed.

The system provides customers with an online platform where they can interact with the restaurant without relying entirely on manual communication methods such as phone calls and messaging applications.

The system also provides administrators with tools to manage restaurant reservations, tables, menu items, customer records, reviews and reports.

## Problem Statement

The restaurant currently relies mainly on manual communication methods to manage customer reservations. This can result in missed bookings, incorrect booking information, double bookings and difficulties in keeping reservation information organised.

The lack of a centralised digital system also makes it difficult for customers to independently manage their reservations and for administrators to efficiently monitor restaurant activities.

This project aims to address these problems by providing a centralised web-based system for managing restaurant reservations and related activities.

## Objectives

The main objectives of the system are to:

- Provide customers with an online reservation platform.
- Allow customers to register and log into the system.
- Allow customers to view the restaurant menu.
- Allow customers to make table reservations.
- Allow customers to make whole-venue reservations.
- Allow customers to cancel reservations.
- Allow customers to view their reservation history.
- Allow customers to submit reviews and ratings.
- Allow administrators to manage reservations.
- Allow administrators to manage restaurant tables.
- Allow administrators to manage menu items.
- Allow administrators to manage customer records.
- Allow administrators to view reviews and ratings.
- Allow administrators to generate reports.
- Improve the organisation and efficiency of restaurant reservation management.
